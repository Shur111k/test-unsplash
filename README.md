# Photo Gallery Test

Навчальний проєкт галереї фотографій. Поточний стан: **етап 1 — каркас Next.js**. Функціонал Unsplash API, галерея, пошук і реєстрація ще не реалізовані. Послідовність роботи описана в [DEVELOPMENT_PLAN.md](./DEVELOPMENT_PLAN.md).

## Перед запуском

- Node.js **20.19 або новіший** та npm. У поточному PowerShell доступний Node.js 20.18.3; перед `npm ci` його потрібно оновити, оскільки одна з залежностей ESLint вимагає щонайменше 20.19.0.
- Якщо `node_modules` немає (наприклад, після клонування репозиторію), із кореня цієї папки виконайте `npm ci`: `package-lock.json` уже створено, тому `npm install` для першого встановлення не потрібен.
- У `.env.local` впишіть отриманий Unsplash Access Key: `UNSPLASH_ACCESS_KEY=ваш_ключ`. Залиште назву без префікса `NEXT_PUBLIC_`: ключ використовуватиметься лише на сервері на наступному етапі. Поки ключа немає, стартова сторінка працює без нього.
- Запустіть `npm run dev` та відкрийте `http://localhost:3000`.

## Перевірки після встановлення залежностей

- `npm run lint`
- `npm run typecheck`
- `npm run build`

Локальний `.env.local`, `node_modules` і результати збірки ігноруються Git. При деплої ключ треба додати до змінних середовища хостингу.
