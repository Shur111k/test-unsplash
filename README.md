# Photo Gallery Test

Навчальний проєкт галереї фотографій. Поточний стан: **етап 4 — керування стрічкою**. Є серверна стрічка, адаптивна masonry-сітка, атрибуція, базова сторінка фото, перемикач 3/5 колонок і сторінкова пагінація. Повні деталі фото, пошук і реєстрація заплановані на наступні етапи. Послідовність роботи описана в [DEVELOPMENT_PLAN.md](./DEVELOPMENT_PLAN.md).

## Перед запуском

- Node.js **22.13 або новіший** та npm. Локально перевірено на Node.js 22.17.1.
- Якщо `node_modules` немає (наприклад, після клонування репозиторію), із кореня цієї папки виконайте `npm ci`: `package-lock.json` уже створено, тому `npm install` для першого встановлення не потрібен.
- У `.env.local` впишіть отриманий Unsplash Access Key: `UNSPLASH_ACCESS_KEY=ваш_ключ`. Залиште назву без префікса `NEXT_PUBLIC_`: ключ читає лише серверний модуль. Без ключа галерея покаже повідомлення про налаштування.
- Запустіть `npm run dev` та відкрийте `http://localhost:3000`.

## Перегляд без витрати ліміту API

В режимі розробки відкрийте `http://localhost:3000/?preview=1`. Це локальний макет галереї з абстрактними SVG-зображеннями, без запитів до Unsplash. У ньому є дві сторінки по 12 карток, тож можна перевірити пагінацію, перемикач і базову сторінку фото. Режим доступний лише при `npm run dev`; звичайна головна сторінка отримує справжні фото через серверний API-запит.

На широких екранах кнопки перемикають 3 та 5 колонок без нового запиту за фото. На вузьких екранах сітка автоматично переходить у 2 або 1 колонку. `page` і `cols` зберігаються в URL; посилання пагінації не підвантажують інші сторінки наперед, щоб не витрачати API-ліміт.

## Перевірки після встановлення залежностей

- `npm run lint`
- `npm run typecheck`
- `npm run test`
- `npm run build`

Локальний `.env.local`, `node_modules` і результати збірки ігноруються Git. При деплої ключ треба додати до змінних середовища хостингу.

## API-шар

`src/lib/unsplash/server.ts` — серверна точка входу для стрічки, окремого фото та пошуку. Вона читає ключ зі змінної середовища й використовує `src/lib/unsplash/client.ts` для запитів. `src/lib/photos.ts` перетворює відповіді API на стабільну модель для майбутнього UI, зберігаючи прямі URL зображень.

Списки та пошук кешуються на 5 хвилин, деталі фото — на 1 годину. Клієнт нормалізує `page` і `per_page`, читає метадані пагінації та розрізняє помилки конфігурації, мережі, авторизації, ліміту запитів і пошкодженої відповіді. Автоматичних live-запитів у тестах немає: `npm run test` працює з підставними відповідями й не витрачає ліміт Unsplash.
